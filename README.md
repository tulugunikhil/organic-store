# organic-store

A simple full-stack marketplace starter with:
- Express + MongoDB backend
- React + Vite frontend
- Tailwind CSS styling

## Setup

### Backend
1. cd server
2. npm install express mongoose cors dotenv jsonwebtoken
3. npm start

### Frontend
1. cd client
2. npm install react react-dom react-router-dom vite @vitejs/plugin-react tailwindcss postcss autoprefixer
3. npm run dev
